## Описание проекта

Двумерная игра Flappy Bird на Python.
Игрок управляет птицей, пролетает между трубами
и получает очки за пройденные препятствия.

## Распределение работы

- Милана — движение птицы и проверка столкновений.
- Мариам — генерация и движение труб, подсчёт очков.
- Совместно — объединение частей, меню, документация и проверка игры.

## Статус проекта

Подготовлено виртуальное окружение и установлена библиотека Pygame.
Создано окно игры размером 480 × 640 пикселей.
Реализованы основной цикл и закрытие окна.
Реализована птица: падение под действием тяжести и прыжок.
Касание верхней или нижней границы завершает игру.
После проигрыша доступен перезапуск.
Реализованы прыжок и падение птицы, генерация движущихся труб,
подсчёт очков, столкновения и перезапуск после проигрыша.

## Структура проекта

- main.py — запуск программы.
- settings.py — настройки игры.
- game.py — окно и основной игровой цикл.
- bird.py — птица, её движение и проверка касания границ.

- Пробел — прыжок.
- R в английской раскладке — перезапуск после проигрыша.

## Установка и запуск

Требуются Python 3.10 или выше и Pygame 2.6.1.
Игра проверена на Windows.

Скачайте проект и откройте его папку в VS Code.
Создайте новое окружение: сохранённое в репозитории venv
может не работать на другом компьютере.

```bash
python -m venv .venv
```

Активируйте его в Git Bash:

```bash
source .venv/Scripts/activate
```

Или в командной строке Windows cmd:

```bat
.venv\Scripts\activate.bat
```

Установите зависимости и запустите игру:

```bash
python -m pip install -r requirements.txt
python main.py
```

## Функциональные возможности

- Падение птицы и прыжок по нажатию пробела.
- Генерация труб со случайным положением прохода.
- Одно очко за каждую полностью пройденную пару труб.
- Проигрыш при касании трубы, верхней или нижней границы.
- Остановка игры после проигрыша.
- Перезапуск клавишей R в английской раскладке.

## Пример использования

Запустите игру и нажимайте пробел, удерживая птицу между трубами.
После столкновения появится сообщение о проигрыше.
Нажмите R, чтобы сбросить счёт и начать заново.

## Организация проекта

- main.py — запуск программы.
- settings.py — параметры игры.
- bird.py — класс Bird: движение птицы и столкновения.
- pipes.py — классы PipePair и PipeManager: трубы и очки.
- game.py — класс Game: события, игровой цикл и отрисовка.

Разделение позволяет разрабатывать птицу и трубы отдельно.
Объединение выполняется через прямоугольник птицы и прямоугольники
препятствий. Графика создаётся программно, внешние изображения
не требуются.
