# Flappy Bird

**Авторы:** Арушанова Милана Авагимовна,
Еганян Мариам Аремновна

**Дисциплина:** Практикум по программированию

**Лабораторная работа:** 3.3

## Описание проекта

Двумерная игра Flappy Bird на Python.
Игрок управляет птицей, пролетает между трубами
и получает очки за пройденные препятствия.

## Распределение работы

- Милана — движение птицы и проверка столкновений.
- Мариам — генерация и движение труб, подсчёт очков.
- Совместно — объединение частей, меню, документация и проверка игры.

## Статус проекта

Подготовлено виртуальное окружение и установлена библиотека Pygame.
Создано окно игры размером 480 × 640 пикселей.
Реализованы основной цикл и закрытие окна.
Реализована птица: падение под действием тяжести и прыжок.
Касание верхней или нижней границы завершает игру.
После проигрыша доступен перезапуск.

## Структура проекта

- main.py — запуск программы.
- settings.py — настройки игры.
- game.py — окно и основной игровой цикл.
- bird.py — птица, её движение и проверка касания границ.

## Требования к системе

- Python 3.10 или выше.
- Pygame 2.6.1.

## Управление

- Пробел — прыжок.
- R в английской раскладке — перезапуск после проигрыша.
